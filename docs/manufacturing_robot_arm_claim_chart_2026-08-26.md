# 구조화 제조 셀 — 핵심 국내 특허 Claim Chart (예비)

> 기준 제품 P0: 고정 외부 비전이 단일 대상의 치수·형상·표면을 검사하고, 데스크톱이
> 검증된 recipe와 목적지를 선택하며, 고정그리퍼 로봇암이 양품/불량/재검사 트레이로
> 이송하는 실물 셀. 무작위 빈, 손목카메라, depth completion, 자동 recipe 생성은 없음.
>

> 필수요소가 P0에서 빠진다는 뜻이며, 비침해 판단이나 권리범위 해석이 아니다.

## 2. 문헌별 요소표

### 2.1 KR20260010291A

공개 청구항 1은 서로 다른 형상·크기·재질·무게·표면의 복수 객체를 자동 인식하고,
센서정보로 조건을 결정하며, 상이한 파지방식이 가능한 파지유닛으로 파지·조작·조립·
이송·검사 중 하나를 수행하는 로봇 시스템이다. 종속항에는 비전·거리·힘 센서,
작업 시나리오 DB, 다중로봇, 모듈형 파지유닛, 성공률 학습, 연속공정이 들어간다.

| 요소 | P0 대조 |
|---|---|
| 복수 객체의 형상·재질·무게·표면 차이 자동 적응 | X — 첫 recipe의 검사대상과 그리퍼는 검증된 범위로 고정 |
| 센서정보에 따른 작업조건 자동결정 | 부분 — 데스크톱이 검증된 recipe 중 선택하나 자동 생성·자동 적응 아님 |
| 상이한 파지방식/모듈형 파지유닛 | X — 고정그리퍼 |
| 파지·조립·이송·검사 중 하나 | O — 이송·분류 |
| 복수 공정의 자동 연계 | 부분 — 검사결과 후 분류만 수행 |

P0가 다품종 자동 recipe, 모듈형 툴, 파지압력 자동보정, 성공률 학습으로 확대되면
이 문헌의 재검토 우선순위가 가장 높다.

### 2.3 KR102797428B1

등록 독립항은 정상영상만 이용한 사용자 단말, 검사서버, 정상영상 저장, AI 비전검사,
결과 안내를 요구하고, 공개된 청구항에는 빅데이터·불량률 알람·3D 스캔·RPA/no-code와

### 2.4 KR102541166B1

등록 독립항은 비전 카메라가 탑재된 로봇의 동작제어, 실시간 동영상 복수 캡처,
AI 양불·불량위치, 모니터링·알람, LED 밝기/색상 변경, 레일 조명, 제품 고정과
카메라 높이조절을 한 시스템으로 묶는다.

P0의 고정 카메라·정지화상·고정조명·규칙판정은 이 조합의 다수 필수요소가 빠진다.
카메라를 로봇 손목으로 옮기거나 색상별 촬영과 AI 알람을 결합할 때 재대조한다.

### 2.5 KR102594983B1

등록 독립항은 카메라의 협동로봇 궤적을 수집하고 2D 영상을 3D 궤적으로 변환한 뒤,
AI로 궤적을 예측해 안전·위험구역을 사용자 단말에 안내하는 서버를 요구한다.

P0는 안전 PLC/STO와 보호장치가 안전기능을 맡고 데스크톱은 작업상태만 표시하므로,
AI 궤적예측을 안전제어 루프로 넣지 않는 한 핵심요소가 빠진다.

### 2.6 KR102443284B1

등록 독립항은 지그에 고정된 친환경 자동차 부재의 설계데이터에서 노즐을 식별·선택하고,
로봇암으로 원뿔형 측정핀을 노즐에 이동·삽입해 직경을 산출·판정하는 구조다.

P0는 단일 대상의 외관·치수 영상검사이며 자동차 노즐, 측정핀 삽입, 로봇이 검사장치를
이동·회전하는 구조가 없다. 접촉식 probe 계측으로 바꾸면 다시 확인한다.

### 2.7 KR102920792B1

공개 명세서상 핵심은 가이드 볼트파이프를 호퍼에서 제1 컨베이어로 보내고, 회전피더가
겹치지 않게 정렬해 제2 컨베이어로 개별공급하며, 상부 비전검사부가 불량을 판단하고
배출·리턴부와 적재부가 자동 처리하는 라인이다.

P0는 구조화 tray/escapement와 로봇암 분류를 사용하고, 동일한 가이드 볼트파이프·
회전피더·2중 컨베이어·리턴부를 복제하지 않는다. 그러나 볼트파이프 제품을 그대로
양산하고 같은 공급라인을 채택할 경우에는 활성 등록권으로 우선 검토한다.

## 3. P0 구현 체크리스트

- [ ] 카메라는 고정 외부형으로 유지
- [ ] 로봇암에는 검사 카메라·열화상·거리센서를 장착하지 않음
- [ ] recipe는 데스크톱에서 사용자 승인 후 버전 고정
- [ ] 자동 recipe 생성, STPM 자동 재학습, RPA/no-code 플로우를 넣지 않음
- [ ] 파지방식은 고정그리퍼 1종으로 시작
- [ ] 로봇은 분류·키팅만 수행하고 비전 판정·안전판정을 대체하지 않음
- [ ] AI 궤적예측을 안전정지의 근거로 사용하지 않음
- [ ] 호퍼·회전피더·2중 컨베이어·불량 리턴을 특정 볼트파이프 특허와 동일하게 구성하지 않음
- [ ] 실제 대상물·조명·카메라·그리퍼 BOM 확정 후 최종 등록청구항으로 재검토

4. 겹침이 남는 문헌은 설계변경, 무효자료, 라이선스 중 하나로 결정한다.
