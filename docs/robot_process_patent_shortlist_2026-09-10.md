# 제조공정 후보의 특허 관점 재선별

조사일: 2026-09-10. 앞서 작성한 7개 후보와 추가 20개 후보의 후속 판단이다.

## 결론

**현재 자료로 등록 가능성이 높다고 확인된 후보는 없다.** 기존 추천은 현장 조사·구현 우선순위였으며 특허성 등급이 아니었다. 이번에는 출원 검토 비용을 투입할 대상을 엄격히 좁힌다.

- **추가 20개만 보면:** 07번 배액을, 아래와 같이 구체화한다는 조건으로 남긴다. 이것도 등록 가능성 ‘높음’ 판정은 아니다.
- **이전 7개까지 합치면:** 도장 마개 제거 후 파손·잔류 확인을 우선 검토하고, 배액 완료 오판 방지를 두 번째로 둔다.
- 이형지 제거·부착은 이전 구현 추천에 포함했지만, 추가로 확인한 비전 검사·정렬 선행기술 때문에 특허 우선 후보에서 제외한다.

순서는 해결하려는 물리적 실패가 명확한지, 그 실패에 대한 구체적인 관측·동작 순서를 제시할 수 있는지, 팀의 제한된 구현 범위에서 비교 실험이 가능한지를 기준으로 한 상대 판단이다. 검색 결과가 적다는 사실을 신규성 증거로 사용하지 않았다.

## 1. 도장 마개 제거 후 파손·잔류 확인 — 이전 후보 2번

### 목표 문제

마개 손잡이 또는 일부만 뽑혔는데 제거 성공으로 처리하여 구멍에 조각이 남는 상황. 실제 협력업체에서 이런 실패가 반복되는지는 아직 확인하지 않았다.

### 구체화할 제안

1. 제품 ID와 제거할 구멍 위치를 대응시킨다.
2. 마개를 뽑아 다른 마개와 섞이기 전에 한 개씩 검사 지그에서 촬영한다.
3. 탄성 변형이 안정된 조건에서 길이·끝단 형상을 기준과 비교한다.
4. 원래 구멍의 제거 후 영상과 함께 판단한다. 구멍이 겉으로 비어 보여도 회수물의 끝단이 불완전하면 해당 제품의 완료 처리를 막는다.
5. 파단이 의심되는 구멍에는 일반적인 반복 당기기를 실행하지 않고 보류한다. 재회수 도구·동작은 별도 검증 후 추가한다.

### 선행기술과 남은 쟁점

[US10458241B2](https://patents.google.com/patent/US10458241B2/en)는 마스킹 플러그 위치·제거 툴을 설명하며, 등록 독립항에 전극·전도성 코팅·용접 결합 등의 요소가 있다. 따라서 ‘로봇 마개 제거’는 출발점 자체가 새롭지 않다. 이 한 문헌과 다른 구조라고 해서 신규성·진보성이 확보되는 것도 아니다.

검토 대상은 **회수한 마개와 원래 구멍을 일대일로 검사하고, 회수물의 불완전성에 따라 제거 완료와 재시도 동작을 바꾸는 구체 구성**이다. 일반적인 제거물 완전성 검사, 파손 공구 검사, 구멍 검사와의 조합이 쉽게 도출되는지 추가 대조해야 한다.

시제품은 손잡이형 마개 한 규격, 고정 제품 지그, 백라이트 검사대, 일반 영상처리로 제한한다. 정상·끝단 파손·손잡이 파손·파지 실패를 섞어, 단순 회수 유무 판정 대비 잔류물 오통과를 비교한다. 실리콘의 늘어남과 재사용 마모에 대한 허용 기준이 필요하다.

## 2. 배액 완료 오판 방지 — 추가 후보 07번

### 목표 문제

물이 더 떨어지지 않더라도, 현재 자세에서 빠져나오지 못하는 액체가 내부 공간에 남아 있는 상황. 낙수가 멈춘 것만으로 배액 완료로 판단하는 오류를 줄이는 것이 목표다.

### 구체화할 제안

1. 비전으로 부품 품종과 자세를 확인하고, 등록된 배출구·내부 공간에 대응하는 동작을 불러온다.
2. 정해진 배액 자세에서 낙수 또는 수집액 질량의 변화를 관측한다.
3. 배출이 멈추면 즉시 끝내지 않고, 해당 공간의 잔류 여부를 드러내도록 사전 등록한 확인용 자세 변경을 한다.
4. 추가 배출이 관측된 경우 그 공간의 배액을 계속하고, 정해진 확인 동작을 마친 뒤에만 다음 공정 이송을 허용한다.
5. 제품에서 물이 나온 시점과 물받이에 도달한 시점의 차이 때문에 다른 자세의 배출량이 섞이지 않도록 정지·관측 구간을 둔다.

### 선행기술과 남은 쟁점

[StingRay](https://www.stingraypartswasher.com/parts-washer-option-robotics-integration.html)는 로봇 연계 세척액 제거·건조를 공개한다. [WO2026010607A1](https://patents.google.com/patent/WO2026010607A1/en)은 센서로 측정한 양과 그 변화에 따라 로봇 기울기를 바꾸는 자동 붓기를 설명한다. [JP5139878B2](https://patents.google.com/patent/JP5139878B2/en)의 배경에도 질량에 따른 건조 종료 제어가 기재되어 있다.

따라서 **기울여 물 빼기, 무게로 종료 판단하기, 센서로 각도 바꾸기**만으로는 추천할 수 없다. 남길 주제는 **배출 중단 후 구획별 확인 동작을 넣어 잔류에 따른 잘못된 완료 판정을 줄이는 방식**이다. 이 역시 통상의 흔들기·다축 배액 시퀀스와 센서 피드백을 단순 결합한 것으로 판단될 가능성이 있어, 특허성은 미확정이다.

시제품은 내부 구조를 아는 작은 부품 한 종류와 미리 정한 자세 목록을 사용한다. 유체 시뮬레이션이나 강화학습은 필요하지 않다. 고정 시간 배액, 고정 자세 순환, 낙수 정지만 보는 종료 방식과 비교하여 잔류량과 처리시간을 측정한다. 외부 영상·낙수만으로 완전 건조를 보증하지 않는다.

## 추가 20개 전체의 처리

아래 ‘제외’는 특허가 절대로 불가능하다는 판정이 아니라 현재 제안 수준에서 우선 출원 검토 대상으로 남기지 않는다는 뜻이다.

| 번호 | 후보 | 이번 판단과 이유 |
|---|---|---|
| 01 | 보관 샘플 | 제외 — 로봇 보관·식별 및 이력 복구 중심으로 차별성 부족 |
| 02 | SMT 릴 반납 | 제외 — 로봇 입출고가 상용화돼 있고 삽입 오류 확인만으로 부족 |
| 03 | 경도 검사 투입 | 제외 — 검사기 연계·안착·재검사 위치 관리의 구체적 차이 미확보 |
| 04 | 검사 커넥터 | 제외 — 연결 확인과 재삽입의 차별화 근거 미확보 |
| 05 | 누설검사 연결구 | 제외 — 시험 전 씰 확인과 연결 실패 감소가 이미 상용 기능 |
| 06 | 지그 칩 청소 | 제외 — 로봇·센서 청소 선행기술과 가까움 |
| 07 | 배액 | 조건부 유지 — 배출 중단 후 잔류 확인 동작으로 좁혀 검토 |
| 08 | 게이트 절단 | 제외 — 기존 절단에 검사·재절단을 붙이는 수준 |
| 09 | 가스켓 분리 | 제외 — 분리·비전 분류가 상용화되어 있고 국소 재처리 기구 미정 |
| 10 | 체결 확인 도장 | 제외 — 체결 연동 표시가 존재하며 중단 복구만으로 차별성 부족 |
| 11 | 실링 테이프 | 제외 — 권취기와 통상적 외관 검사 조합 수준 |
| 12 | 오링 장착 | 제외 — 전용 장착·검사·보정과 구별되는 구체 구성 미확보 |
| 13 | 케이블타이 | 제외 — 로봇 결속 공구가 존재하고 검사 조건 추가만으로 부족 |
| 14 | 열수축 튜브 | 제외 — 삽입·가열·위치 보정의 차별화 근거 미확보 |
| 15 | 이형지·패드 | 제외 — 추가 특허에서 비전 검사·정렬까지 확인 |
| 16 | 그리스 도포 | 제외 — 비전 도포·정량 계측·보충의 구체적 차이 미확보 |
| 17 | 명판 리벳 | 제외 — 식별정보 대조·작업 허용 조건 중심으로 진보성 근거 부족 |
| 18 | 상자 개봉 | 제외 — 특허를 명시한 상용 시스템과 가까움 |
| 19 | 외포장 비닐 | 제외 — 자동 디배거가 존재하며 잔류 검사 외 구체 기구 미정 |
| 20 | 접이식 상자 | 제외 — 전개기가 존재하며 잠금 확인·재누름만으로 부족 |

각 항목의 상용 사례와 기존 조사 근거는 [추가 20개 보고서](practical_robot_process_20_more_candidates_2026-09-10.md)를 따른다. 이번에 20개 모두의 한국 등록 청구항·심사경과를 조사한 것은 아니다.

특히 [WO2021087622A1](https://patents.google.com/patent/WO2021087622A1/en)은 로봇 테이프 부착 시스템에 영상·레이저 기반 부착 확인과 정렬을 설명한다. 폼 패드 개별 박리와 완전히 동일한 장치라고 단정하지 않지만, ‘비전 검사·좌표 보정을 추가한다’는 수준의 제안이 약하다는 근거로 반영했다.

## 다음 판정에 필요한 것

남긴 두 후보도 청구항 수준의 국내외 대조와 실험을 통과해야 한다. **현재 등록 가능성 높음 판정 0개, 구체화 후 우선 조사할 조건부 후보 2개**로 구분한다. 국내에 판매되지 않는다는 이유로 외국 공개기술을 선행기술에서 제외하지 않는다. [특허법 제29조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030488663)
