### 도 1 — 전체 시스템 구성도

```
   주문 시스템(80) ── 회수 순서(변경불가) ──┐
                                            ▼
 [상류] ══ 컨베이어(10) ═══════════════▶ [로봇 작업역]
          │                                  │
        식별부(20)                          로봇(30)
        (코드 판독:                      ┌───┴───┐
         ID·목적지·                   흡착        ▼
         회수순서·치수·             그리퍼(32)  출고 팔레트(40)
         중량·방향)                    │        (목적지별 다수)
                                       ▼
                              임시 적층부(50)  ◀── 센서부(60)
                              (3차원 적층)        (실제 위치·성공 확인)
                                       ▲
                                   제어부(70)
                          (S1~S9, G1·G2·G3 판정)
```
서술: 컨베이어(10) 상류의 식별부(20)가 물품 도착 전 코드를 읽어 주문 시스템(80)과 연계하고,
회수 순서는 주문 시스템(80)이 **부여**한다(제어부 변경 불가). 로봇(30)은 상면 흡착
그리퍼(32)로 출고 팔레트(40) 또는 임시 적층부(50)에 물품을 놓고 꺼낸다. 센서부(60)가 실제
결과를 확인한다.

### 도 2 — 전체 제어 흐름도 (S1~S9)

```
 (S1) 신규 물품 정보·회수 순서 획득
        │
 (S2) 출고 팔레트 즉시 적재 가능? ──── 예 ──▶ 출고 팔레트 적재 ──▶ (S9)
        │ 아니오
 (S3) 임시 적층부 배치 후보 집합 생성 {C1,C2,…,Cn}
        │
 (S4~S7) ┌─ 각 후보 Ci 에 대해: ───────────────┐
         │   (S4) 신규 물품 가상 배치            │
         │   (S5~S6) 가상 회수 검증 [도 3]        │
         │        └ 통과? ── 아니오 ─▶ Ci 탈락 ──┤
         │              예                        │
         │   (S7) Ci 채택 후보에 추가             │
         └───────────────────────────────────────┘
        │
 (S8) 채택 후보 중 도착시각 vs 회수소요시간 비교
      → 적재 / 회수 / 감속 / 정지 선택 + 최종 배치 위치 결정
        │
      로봇으로 실제 적재
        │
 (S9) 센서 실제 위치 확인 → 계획과 상이하면 (S5~S7) 재검증
      (실제 적재 성공 확인 전 후행 선행조건 미완료 처리)
```

### 도 3 — 가상 회수 검증 서브루틴 (S5~S6, 발명의 핵심)

```
 입력: 배치 후보 Ci (신규 물품 가상 배치된 임시 적층부 상태),
       부여된 회수 순서 [o1, o2, …, ok]
        │
   j ← 1  (회수 순서 인덱스)
        ▼
 ┌───────────────────────────────────────────────┐
 │ 대상 = oj (현재 순서에서 꺼내야 할 물품)         │
 │                                                 │
 │ G1: oj 상면 노출영역 ⊇ 흡착 풋프린트?  ──아니오─┐│
 │        │ 예                                     ││
 │ G2: 로봇+그리퍼+파지한 oj 스윕볼륨의            ││
 │     무충돌 반출 경로(IK 해) 존재?      ──아니오─┤│
 │        │ 예                                     ││
 │ G3: oj 제거 후 잔여물 각각 지지다각형 내        ││
 │     무게중심 & 허용하중 이내?          ──아니오─┤│
 │        │ 예 (G1 ∧ G2 ∧ G3)                      ││
 │   oj 가상 제거 → 잔여 상태 갱신                 ││
 │   j ← j+1                                        ││
 │        │                                        ▼│
 │   j > k ?  ── 아니오 ──▲(루프)          [Ci 탈락]│
 │        │ 예                             return 실패│
 │  return 성공 (Ci 채택 가능)                      │
 └───────────────────────────────────────────────┘
```
핵심: G1·G2·G3는 **AND**이며 **매 제거 단계 j마다** 평가된다. 하나 제거하면 잔여 상태가
바뀌므로 다음 단계는 갱신된 상태로 재평가한다(청구항 5·17).

### 도 4 — G1 상면 흡착 파지 판정

```
   [측면도]              [평면도: oj 상면]
   ┌────┐ ← C (위 물품)   ┌──────────┐
   │ C  │                 │▓▓▓▓░░░░░░│ ▓ = C에 덮인 영역
   ├────┴──┐              │▓▓▓▓░░░░░░│ ░ = 노출 영역
   │  oj   │              │░░░░[▦▦]░░│ ▦ = 흡착 풋프린트
   └───────┘              └──────────┘
                          노출영역 ⊇ 풋프린트 ? → 예: G1 통과
                          (청구항 3: 노출영역 중 풋프린트 비율 ≥ 문턱값)
```

### 도 5 — G2 무충돌 회수 경로 (파지물 포함 스윕 볼륨)

```
   이웃 B          이웃 D          ← oj를 위로 들어올릴 때
   ┌──┐  ┌──────┐  ┌──┐            그리퍼+oj의 스윕 볼륨(점선)이
   │B │  │[그리퍼]│  │D │            B·D와 충돌하는지 검사.
   │  │  │▒▒oj▒▒│  │  │            + 로봇 링크 IK 해 존재 여부.
   └──┘  └──────┘  └──┘            충돌 없고 IK 해 있으면 G2 통과.
        ↑ 반출 경로(스윕 볼륨)
```

### 도 6 — G3 제거 후 잔여 안정성

```
   [oj 제거 전]         [oj 제거 후]
   ┌──┐                 ┌──┐  E의 무게중심 투영(×)이
   │E │ ← 위 물품        │E │  남은 지지 다각형 밖?
   ├──┴─┐               └┬─┘   → 전복 위험 → G3 실패
   │oj  │ 제거            │      투영이 안이면 → G3 통과
   ├────┤          ┌─────┘      (청구항 4: 경계까지 마진 ≥ 문턱값)
   │ F  │          │ F  │  지지다각형 = F 상면
   └────┘          └────┘
```

### 도 7 — 배치 후보 채택/탈락 예시 (회수 순서: B 먼저, 그다음 C)

```
 후보 α: C를 B 위에      후보 β: B를 C 위에      후보 γ: B·C 나란히
   ┌──┐                   ┌──┐                    ┌──┐┌──┐
   │C │ ← 먼저 꺼낼 B를    │B │ ← B 먼저 꺼냄 OK   │B ││C │ 그리퍼 진입
   ├──┤   덮음            ├──┤                    └──┘└──┘ 측면 간격 부족
   │B │                   │C │                    (G2 실패)
   └──┘                   └──┘
   G1 실패 → 탈락          G1·G2·G3 통과 → 채택     G2 실패 → 탈락
```

## B. 실험 계획서

**목적:** 청구항 1의 "물리 3항 AND 게이트"가 진보성(비자명성)을 뒷받침함을 정량 입증한다.
즉 **"가상 회수 검증(게이트)의 유무가 회수 실패·재적재에 유의미한 차이를 만든다"**를 보인다.
진보성 방어의 핵심 근거이므로(§9-1의 2), 출원 전/직후 확보를 권고한다.

### B-1. 독립변수 (처리군)

같은 물품 시퀀스·같은 임시 적층부에 대해 **배치 결정 방식만** 바꾼다.

| 군 | 배치 결정 방식 | 대응 |
|---|---|---|
| **T0 (대조)** | 회수 검증 없이 공간 효율·빈자리로만 배치(무진식) | 종래기술 |
| T1 | 회수 순서 벌점(soft score)만 반영, 물리 게이트 없음(HD조선식) | 부분 종래 |
| T2 | 안정성(G3)만 검사 | 부분 |
| **T3 (발명)** | G1 ∧ G2 ∧ G3 매 단계 AND 게이트로 후보 탈락 | 청구항 1 |

핵심 대비는 **T0 vs T3** 및 **T2 vs T3**(G1·G2 추가 효과 분리).

### B-2. 통제변수 (모든 군 동일)

- 물품 시퀀스(도착 순서·치수·중량·목적지·회수 순서) — 동일 난수 시드로 생성한 세트.
- 임시 적층부 용량·형상(3차원 적층), 상면 흡착 그리퍼 사양, 로봇 기구학.
- 출고 팔레트 구성, 컨베이어 속도.
- 시나리오 수: ≥ 30 세트/군(통계 검정 위해), 물품 수 각 세트 50~200개.

### B-3. 종속변수 (측정)

| 지표 | 정의 | 기대(T3) |
|---|---|---|
| **회수 실패율** | 회수 시점에 G1·G2·G3 중 하나라도 불가하여 못 꺼낸 비율 | T3 ≈ 0, T0 ≫ 0 |
| **재배치 횟수** | 회수를 위해 다른 물품을 임시로 치운 횟수 | T3 최소 |
| 컨베이어 정지시간 | 누적 정지·감속 시간 | 비교 |
| 처리량 | 단위시간당 출고 팔레트 적재 물품 수 | 트레이드오프 확인 |
| 계획시간 | 배치 결정당 평균 계산시간 | T3가 가장 큼(비용) |
| 계획 제한시간 초과율 | 제한시간 내 후보 못 찾은 비율 | 파라미터 민감도 |

### B-4. 가설·검정

- **H1:** 회수 실패율(T3) < 회수 실패율(T0). — Mann-Whitney U 또는 t-검정, α=0.05.
- **H2:** 재배치 횟수(T3) < (T0). 
- **H3:** G1·G2를 뺀 T2보다 T3의 회수 실패율이 낮다(물리 3항 결합의 시너지 = 진보성 논거).
- **트레이드오프 명시:** T3의 계획시간·처리량 손실이 회수 실패·재배치 감소로 상쇄됨을 제시
  (§6-3의 제한시간 파라미터로 조절 가능함도 함께).

### B-5. 실행 방식 (2단계)

1. **시뮬레이션(우선, 저비용):** 물품 시퀀스 생성기 + 임시 적층부 상태 모델 + G1/G2/G3
   판정 모듈 + 로봇 IK/충돌(기존 MoveIt 등 활용). 30+ 세트 × 4군 배치 실험.
   → 이 저장소(FR3 빈피킹 기반)의 기존 IK·충돌 검사 자산 일부 재사용 가능성 검토.
2. **실물 검증(핵심 소수):** 시뮬레이션에서 T0가 실패하고 T3가 성공한 대표 시나리오
   3~5건을 실제 로봇 + 상면 흡착 그리퍼 + 적층 버퍼로 재현. 진보성 설명의 결정적 증거.

### B-6. 산출물

- 군별 지표 표 + 분포 그래프(회수 실패율·재배치 횟수 박스플롯).
- T0 실패 / T3 성공 대표 시나리오의 단계별 스냅샷(도 7 형태) — 명세서 [실시예] 및
  진보성 의견서에 직접 인용.

### B-8. 시뮬레이션 실측 결과 (2026-09-09 실행 완료)

시뮬레이션 단계(B-5의 1)를 **실제 구현·실행**했다. 코드는 기존 로봇암의 기하 엔진
(`src/bin_picking/bin_picking/geometry.py`의 선분–선분 거리·레이–사각형)을 G2(회수 경로
충돌) 판정에 재사용한다. 실행 코드·결과: `experiments/virtual_retrieval_sim/`
(seed 20260909, 시나리오 각 300, 재현 가능).

**단일 조건(스택 5 × 높이 5 = 25칸, 12박스 = 48% 점유):**

| 전략 | 평균 재배치 | 회수 실패 | 계획 평가 |
|---|---:|---:|---:|
| T0 종래(공간효율) | 5.37 | 0% | 0 |
| T1 순서 벌점(soft) | 6.64 | 0% | 0 |
| T2 안정성만 | 5.59 | 0% | 60 |
| **T3 발명(G1∧G2∧G3+가상회수)** | **4.07** | 0% | 47 |

- 재배치: T0 대비 T3 **24% 감소**(쌍대 t=11.7, n=300).
- 순수 기여 분해: **T2→T3 t=17.7**(G1·G2 = 회수 파지·경로 추가분), **T1→T3 t=22.5**
  (soft 벌점 대비 hard 게이트).

**포화도 스윕(같은 버퍼, 박스 8~20 = 점유 32~80%): T0 재배치 → T3 재배치 (감소, 쌍대 t)**

| 점유 | T0 | T3 | 감소 | t |
|---:|---:|---:|---:|---:|
| 32% | 1.70 | 0.85 | 50% | 15.7 |
| 48% | 5.37 | 4.07 | 24% | 11.7 |
| 64% | 10.46 | 8.35 | 20% | 13.1 |
| 80% | 17.54 | 15.08 | 14% | 10.9 |

**해석(진보성 논거):** ① 개별 요소(순서 벌점 T1·안정성 T2)만으로는 재배치가 많이 남고,
G1∧G2∧G3를 가상 회수의 매 단계에 **AND로 결합할 때(T3)** 비로소 재배치가 최소화된다 —
결합의 순수 기여가 통계적으로 확인된다(t≫2). ② 모든 점유율에서 T3 우위가 유지되며 붐빌수록
절대 격차가 커진다. ③ 버퍼 여유 구간에서 회수 실패는 0이고, 포화 극단의 회수 불가는 청구항
9·11(제한시간 구분·복구 동작)의 대상이다. ④ T3의 계획 평가 비용(후보당 가상 회수)이
트레이드오프이며 §6-3의 제한시간으로 조절된다.

**남은 것(실물 검증):** B-5의 2단계(대표 시나리오 3~5건 실물 로봇+상면 흡착+적층 버퍼
재현)는 장비가 필요해 미실행. 시뮬레이션은 진보성 논거를 정량 확보했고, 실물은 이를 확인하는
보강 증거다.

### B-7. 주의 (자기공개 신규성)

실험 결과·코드·영상을 **출원 전에 외부 공개하지 말 것**(논문·저장소 공개·시연). 한/미 12개월
유예가 있으나 유럽 절대신규성 등을 고려하면 **출원 후 공개**가 안전(§9-2의 5 참조).
