## 1. 출원 1 — S1 마스터 핸드셰이크 (권장 독립항 [1′])

**개정 독립항 요지(전문은 문서 2 §8.3):** 인식-랭킹부가 (A) **로봇 기구학·도달성 모델
무보유**, 거부 이력만으로 재랭킹 / (B) 거부를 작업공간 격자에 누적한 **거부 우도로
사전 감점**(T1 흡수) / (C) **비신경망 온라인 선형** 랭커 + 물리판정 하드게이트 /
(D) **장면 진전 시 실패 스트릭 무효화**.

**신규성 근거:** US11511415B2 청구1은 "실행가능성 검증→불가시 대체선택"까지만(=넓은
버전과 동일). 우리 (A)~(D) 6요소는 전수 부재. 2111.02571은 도달성을 **시뮬 학습**(기구학
기반)이라 (A)와 구별.

**실시예(우산):** 빈피킹/키팅/트레이 디네스팅/팔레타이징 — 청구항 15~18.

## 2. 출원 2 — 다신호 융합 파지검증

**독립항 요지(전문은 문서 3):** 리프트 후 **상승량 + 개구폭 + 관절편차(비힘센서)** 3신호를
우선순위/다수결로 융합해 파지성공 확정. 종속 [6] 신호 상충 시 **걸림(entangled) 진단**이
진보성 훅.

**정직성:** z-상승 1차 + 폭 폴백은 **코드 실재**(`pick_place_node.py:856-899`), 관절편차·걸림
진단은 **제안 확장(미구현)** → 출원 전 간이 실증 데이터 권장.

## 2-1. 출원 3 — PS1 무정지 실패 트리아지 셀

**독립항 요지(전문은 문서 4):** 실행부가 실패를 **유형화 사유**로 회신 → 감독부가 재시도/
차순위/**대상 격리**/운영자 인계를 **자율 트리아지** → 격리 대상 남기고 **셀 무정지 계속**
→ **잔여만** 디지털 섀도우와 함께 운영자 인계 → **물리 안전은 독립 계층**(트리아지가 우회 불가).

**신규성 근거:** US9682480(원격조작 복구)는 운영자가 복구 절차 선택·지령(전량). 우리 자율
트리아지 + 무정지 계속 + 잔여만 인계는 부재. 국내 핵심쿼리 0건.

**정직성:** 유형화 사유·자율 트리아지·개입 명령·안전정지·디지털 섀도우는 **코드 실재**,
`SKIP_CURRENT`/`HOLD_BOLT`는 현재 ACK-only(로봇 미처리) → 청구 [8] 위해 처리 추가 필요.

**S1과의 관계:** S1=후보 선택 핸드셰이크, PS1=실패 시 셀 생존 — **별개 발명**(층위 다름).

## 5. 정직성·범위 한계

- 본 패키지는 **웹검색 + KIPRIS 예비검색 + 특허 1건/논문 2건 대조** 수준이다. 전체
  특허 패밀리·심사경과·법적상태·FTO는 미확인. 인용 문헌·특허번호는 검색 결과 기반이며
  변리사 원문 재확인 필요.
- 출원 1의 개념(주체분리·거부 되먹임)은 **우리 시스템이 이미 수행 중** — 자기공개
  게이트(§4)가 최우선.
- 근거 자산은 실제 코드/프로토콜(`desktop_protocol.md`, `selection.py`, `grasp_selector.py`,
  `pick_place_node.py`)이며 초안 문구는 이에 정합하도록 작성했다.
