## 4. 하중 변화 상한의 구체적인 식

아래 값은 기존 코드와 맞춰 kg 단위의 질량 등가 하중으로 표현한다. N 단위를 쓰려면 중력가속도를 일관되게 곱한다. 충돌 거리의 m 단위와 합쳐 하나의 점수로 만들지 않는다.

- `m_i`: 물체 i의 자중에 해당하는 질량
- `L_i`: i가 위에서 전달받는 하중
- `T_i = m_i + L_i`: i가 아래에 전달하는 총 하중
- `s_ji`: 상부 j가 하부 i에 전달하는 분담비. 0 이상이며 한 상부 물체의 분담비 합은 1
- `C_i`: i의 허용 상부하중. 이번 실험에서는 고정값

기준 상태의 계산은 다음과 같다.

```text
L_i⁰ = Σ_j s_ji⁰ T_j⁰
T_i⁰ = m_i⁰ + L_i⁰
μ_i = C_i - L_i⁰
```

새 상태의 변화 범위를 `|m_i-m_i⁰| ≤ ε_mi`, `|s_ji-s_ji⁰| ≤ ε_sji`로 얻었다고 하자. 위에서 아래로 다음 식을 한 번씩 계산한다.

```text
B_Li = Σ_j [(s_ji⁰ + ε_sji) B_Tj + ε_sji T_j⁰]
B_Ti = ε_mi + B_Li
```

상부에서 아무 하중도 받지 않는 물체는 `B_Li=0`, `B_Ti=ε_mi`로 시작한다. `T_j⁰ ≥ 0`이고 그래프가 고정된 비순환 그래프일 때, `|L_i-L_i⁰| ≤ B_Li`가 성립한다.

### 식이 성립하는 이유

하나의 연결에서 전달하중 변화는 다음과 같다.

```text
sT - s⁰T⁰ = s⁰(T-T⁰) + (s-s⁰)T⁰ + (s-s⁰)(T-T⁰)
```

삼각부등식으로 절댓값 상한을 취하면 위 합의 각 항을 얻는다. 이를 상부부터 순서대로 적용하면 하부에서도 상한이 유지된다. 이 논증은 실수 연산을 가정한 **지정한 하중 분담 모델 내부에서의 수학적 성질**이다. 실험은 일반 부동소수점과 오차 허용치를 사용했으며, 바깥 방향 반올림을 갖춘 인증 구간 연산을 구현한 것은 아니다. 실제 접촉 반력이 면적비를 따르는지는 증명하지 않는다. 구간 전파와 삼각부등식 자체를 새 발명 원리로 주장하지 않는다.

### 실제 재사용 조건

```text
접촉 그래프와 모델 전제가 유지됨
AND 모든 입력 오차의 유한한 상한을 확보함
AND C_i - L_i⁰ > B_Li + 수치 여유
→ 해당 하중 검증 결과 재사용 가능
```

이를 만족하지 않는 경우의 의미는 **재검증 필요**이다. 곧바로 물체가 불안정하다는 뜻이 아니다. 최신 상태와 필요한 불확실성 범위로 다시 검증하고, 그 결과가 불허이면 동작을 보류한다. 새로운 전체 검증에서의 실패와 보수적인 상한 때문에 생긴 재검증을 구분해 기록한다.

허용하중 자체가 `ε_Ci`만큼 줄 수 있으면 오른쪽에 `ε_Ci`를 더해야 한다. 이번 수치 실험에서는 허용하중 변화는 다루지 않았다.

### 수치 예시

상부 A가 B와 C에 각각 50%씩 전달하고, A의 기준 총 하중이 2.0 kg이라고 하자. A 총 하중의 변화 상한이 0.1 kg이고 B 분담비의 변화 상한이 0.05이면:

```text
B_B = (0.50 + 0.05) × 0.10 + 0.05 × 2.0 = 0.155 kg
```

B의 기존 하중 여유가 0.20 kg이면 이 항목을 재사용할 수 있다. 여유가 0.10 kg이면 다시 계산해야 한다. B 아래의 물체에도 변화를 계속 전달한다. B가 A와 가까이 있다는 이유로 B만 검사하고 멈추지 않는다.

## 5. 분담비 변화 상한을 얻는 방법 — 아직 실험 코드에 미연결

분담비 오차를 임의로 부여하는 데서 끝내면 발명 구현이 충분히 구체적이지 않다. 첫 구현 후보는 고정 크기·축 정렬 직육면체의 접촉 직사각형을 구간으로 계산하는 것이다.

물체 p와 q의 x축 원점 범위가 각각 `[l_p,u_p]`, `[l_q,u_q]`이고 크기가 `d_p,d_q`이면, 겹침 폭의 보수적인 범위는 다음으로 잡을 수 있다.

```text
w_min = max(0, min(l_p+d_p, l_q+d_q) - max(u_p,u_q))
w_max = max(0, min(u_p+d_p, u_q+d_q) - max(l_p,l_q))
```

y축에도 같은 계산을 적용하고 두 폭을 곱하여 접촉 면적의 범위 `[A_i_min,A_i_max]`를 얻는다. 같은 상부 물체에 대해:

```text
s_i_min = A_i_min / (A_i_min + Σ_(h≠i) A_h_max)
s_i_max = A_i_max / (A_i_max + Σ_(h≠i) A_h_min)
ε_si = max(|s_i_min-s_i⁰|, |s_i_max-s_i⁰|)
```

분모가 0이거나 어떤 접촉이 생기고 없어질지 확정할 수 없으면 재사용을 금지한다. 같은 접촉 ID가 유지돼도 면적비는 달라질 수 있으므로 분담비 상한은 다시 확인한다.

이 식은 x·y축 평행이동과 고정 크기라는 전제에 한정된다. 회전하는 직사각형의 접촉 면적에 그대로 적용하지 않는다. z 오차 때문에 접촉 여부가 불확실하거나 기울기·변형이 생기면 이 초기 모델 밖으로 분류한다. 단순히 높이 차가 작다는 이유로 실제 하중 지지를 확정하지 않는다.

## 6. 충돌 결과의 재사용 조건 — 설계 규칙, 이번 실험 미구현

저장된 경로 전체의 최소 충돌 여유가 `d⁰`이고 요구 여유가 `d_req`라고 하자. 장애물과 로봇·그리퍼·운반물의 형상 변화에 대한 Hausdorff 거리 상한을 각각 `h_obs`, `h_motion`으로 잡으면 다음을 사용할 수 있다.

```text
d⁰ - d_req > h_obs + h_motion
```

강체의 평행이동 오차 상한이 `e_t`, 회전각 오차가 `e_θ∈[0,π]`, 회전 기준점에서의 최대 반경이 r이면 점 변위의 상한으로 `e_t + 2r sin(e_θ/2)`를 사용한다. 경로 자체나 운반물 크기가 바뀌면 기존 항목을 그대로 재사용하지 않는다.

이 규칙을 로봇 경로 전체에 적용하려면 연속 경로 또는 구간 사이 움직임까지 포함한 외피가 필요하다. 몇 개 궤적 표본점의 거리만으로 연속 충돌 회피를 보장하지 않는다. 새 장애물·이동한 장애물은 팽창된 통과 영역과 대조하여 새 의존관계를 찾아야 한다. 과거에 기록된 장애물 목록만 검사하면 안 된다.

## 7. 무효화와 실행 규칙

1. 새 관측에서 변경 물체·오차 범위를 구한다. 물체 누락, 식별자 교체, 경로·모델 버전 변경도 상태 변화로 취급한다.
2. 기존 접촉뿐 아니라 새 접촉 가능성을 검사한다. x·y 겹침과 z 접촉 가능성이 모두 있는 새 물체 쌍은 무시하지 않는다.
3. 접촉 생성·소실이면 기존 그래프와 새로운 가능 그래프의 합집합에서 영향을 받는 연결 성분을 무효화한다. 기하학적 통과 영역이 영향을 받은 경로도 무효화한다.
4. 접촉과 모델이 유지되는 항목만 변화 상한과 기존 여유를 비교한다. 변화가 전체로 전파되거나 범위를 한정할 수 없으면 전체 재검증으로 전환한다.
5. 충돌, 지지면·무게중심, 하중, 로봇 도달성 등 그 동작에 필요한 검증이 모두 유효할 때만 실행 후보로 넘긴다. 이번 하중 실험 하나가 이 모든 검증을 대신하지 않는다.

접촉이 변경됐을 때 기존 기준의 상한을 새 그래프에 그냥 적용하지 않는다. 이번 도구의 접촉 변경 검사는 입력받은 그래프 ID를 비교하는 단위 수준이다. 센서로 새 접촉을 찾아내는 기능은 아직 구현하지 않았다.

### 6개 목적 사례

- 최상부 질량 변화가 떨어진 하부 물체에 과부하를 만드는 경우.
- 질량은 같지만 분담비 변화만으로 과부하가 되는 경우.
- 기존 접촉이 사라지는 경우.
- 새 접촉이 생기는 경우.
- 오차 구간이 넓어 중앙 상태는 허용되지만 재사용 조건은 통과하지 못하는 경우.
- 작은 이동을 반복할 때 기준 상태를 잘못 옮기면 누적 변화를 놓치는 경우.

### 시간 측정: 개선 효과 없음

단위 μs, 각 크기 1,000회 중앙값. 기존 전체 하중 결과와 검증 기록의 사전 생성 비용은 제외했다. 의존성 기준선은 역방향 인접 목록이 준비된 상태로 측정했다.

| 물체 수 | 전체 하중 계산+한계 비교 | 영향받은 하중만 갱신+비교 | 상한 판정+필요시 중앙 상태 재계산 |
|---|---:|---:|---:|
| 12 | 2.17 | 4.89 | 11.27 |
| 24 | 3.62 | 5.70 | 19.49 |
| 36 | 5.03 | 6.06 | 27.60 |

세 번째 방식은 오차 구간을 위한 충분조건도 계산하므로 중앙 상태만 계산하는 첫 방식보다 더 강한 판단을 일부 수행한다. 이 비교는 동일한 강건성의 검증기끼리 비교한 속도 개선 실험이 아니다. 특히 재검증 필요 상태에서 오차 구간 전체를 검증하는 비용은 포함하지 않았다. 상한을 계산하면 자연히 빨라질 것이라는 가정을 점검하는 수치 비용 조사다.

시간 차이는 작은 Python 루프에서 측정됐으며 순서 무작위화·여러 프로세스 반복·실제 작업 부하 검증을 하지 않았다. 비율을 로봇 사이클타임이나 생산성 향상 수치로 사용하지 않는다. 다만 **현재 구현에는 속도 향상의 증거가 없다**는 결론은 분명하다.

## 9. 발명 검토에 주는 의미와 다음 수용 기준

현재 Tanalysis 보고서는 조합의 차이를 검토할 여지가 있다고 평가했다. 이번 작업은 그중 비어 있던 하중 상한을 계산식으로 채운 것이다. 이 계산식이 선행기술에 없다는 결론은 도출하지 않았다.

- [KR20240042480A](https://patents.google.com/patent/KR20240042480A/ko)의 변경된 데이터와 연관된 위험 재평가와 구분해야 한다.
- [KR20230128502A](https://patents.google.com/patent/KR20230128502A/ko)의 충돌 정보 저장·재사용과 구분해야 한다.
- [Safety Certificates 연구](https://ottelab.com/html_stuff/pdf_files/Bialkowski.Otte.ea.IJRR16.pdf)의 여유 기반 충돌검사 생략과 구분해야 한다.

따라서 현 단계에서 ‘선택적 재검증으로 계산량을 줄였다’는 발명 효과를 주장하지 않는다. 다음 검증은 다음 기준을 충족해야 의미가 있다.

1. 실제 박스 배치와 관측 오차로부터 접촉·분담비 범위를 자동 생성한다. 애매한 접촉을 누락하지 않아야 한다.
2. 힘·모멘트 평형을 포함한 정적 접촉 해석 또는 연속 경로 충돌검사처럼 비용이 실제로 큰 검증기를 정한다.
3. 그 검증기와 이 상한 모델의 연결을 증명한다. 면적비 모델에서 통과했다는 이유로 다른 정적 해석 결과를 재사용하지 않는다.
4. 같은 오차 조건과 허용 실패 기준에서 전체 재검증, 일반 의존성 갱신, 제안 방식을 비교한다. 새 접촉 탐색, 관계 관리, 상한, 무효화, 재계산 비용을 모두 포함한다.
5. 독립적인 Gazebo 실행에서 전도·미끄러짐·충돌을 따로 평가한다.
6. 일반적인 의존성 갱신보다 추가 효과가 없거나 상한 처리 비용이 더 크면, 계산시간 절감을 중심으로 한 이 후보의 우선순위를 낮춘다.
