# 가상 회수 검증 시뮬레이션 (특허 진보성 실증)

혼합 박스 팔레타이징에서 **임시 적층부(버퍼)에 놓기 전에 외부 부여 회수 순서대로 실제로
꺼낼 수 있는지를 물리 3항 게이트(G1·G2·G3)로 검증**하는 발명의 효과를, 종래 방식과
동일 시나리오로 비교하여 정량 입증하는 실험이다.

- 특허 명세서: `../../docs/virtual_retrieval_patent_spec_draft_2026-09-09.md`
- 선행 조사: `../../docs/virtual_retrieval_verification_claim_chart_2026-09-09.md`
- 도면·실험 계획: `../../docs/virtual_retrieval_patent_figures_and_experiment_2026-09-09.md`

## 기존 로봇암 코드와의 관계

이 디렉토리는 기존 로봇암(`src/bin_picking`)과 **분리된** 실험 공간이나, 로봇의 실제 기하
엔진을 **재사용**한다. `sim.py`는 `src/bin_picking/bin_picking/geometry.py`의
`GeometryMixin._seg_seg_dist`(선분–선분 거리)와 `_ray_rect_travel`(레이–사각형)을 그대로
import하여 **G2(회수 경로 충돌)** 판정에 사용한다. 이 두 함수는 빈피킹 파지 개구 계산과
동일한 메커니즘으로, 상면 흡착 그리퍼가 파지한 박스를 수직 반출할 때 이웃 박스와의 간섭을
판정하는 데 재사용된다. (로봇 실물·ROS 없이 순수 기하 함수만 로드된다.)

## 모델

- 상면 흡착 그리퍼: 스택 맨 위 박스만 상면이 노출되어 흡착 파지 가능(G1).
- 임시 적층부 = S개 스택 × 최대 높이 H. 박스는 위로 적층(3차원).
- 각 박스: 폭(footprint)·중량·**외부에서 부여되어 변경 불가한 회수 순서**.
- 물리 3항 게이트:
  - **G1(파지):** 대상이 스택 맨 위 = 상면 노출 흡착 가능.
  - **G2(경로):** 파지한 박스를 수직 반출할 때 이웃 스택과 무충돌(기존 `_seg_seg_dist` 사용).
  - **G3(안정성):** 넓은 박스를 좁은 박스 위에 얹는 오버행 배치 배제.
- 배치 전략: **T0**(종래·공간효율) / **T1**(순서 벌점 soft) / **T2**(안정성만) /
  **T3**(발명: 물리 3항 게이트 하 회수 비용 최소 배치 = 가상 회수 검증).

## 실행

```bash
python3 experiments/virtual_retrieval_sim/run_experiment.py     # 단일 조건(12박스/25칸)
python3 experiments/virtual_retrieval_sim/run_sweep.py          # 포화도 스윕(8~20박스)
```

결과는 `results/experiment_result.md`, `results/sweep_result.md`에 저장된다.

## 핵심 결과 (seed 20260909, 시나리오 각 300)

- 버퍼 여유 조건(48% 점유): **재배치 T0 5.37회 → T3 4.07회 (24% 감소, 쌍대 t=11.7)**,
  회수 실패 전 전략 0%.
- 순수 기여 분해: T2(안정성만)→T3 차이 t=17.7 = G1·G2(회수 파지·경로) 추가분,
  T1(벌점)→T3 차이 t=22.5 = soft score 대비 hard 게이트의 효과.
- 포화도 스윕: 모든 점유율(32~80%)에서 T3 재배치 우위 유지, 붐빌수록 T0−T3 격차 확대.

## 파일

- `sim.py` — 모델·물리 3항 게이트·전략(기존 geometry 재사용).
- `run_experiment.py` — 단일 조건 4전략 비교·통계.
- `run_sweep.py` — 포화도 스윕(T0 vs T3).
- `results/` — 실행 산출물(git 추적 대상, 재현 가능).

## 한계 (명세서 §9와 정합)

- 순수 기하/이산 시뮬레이션이다. 실물 로봇 검증(대표 시나리오 3~5건)은 별도 필요.
- online(신규 박스 도착)이므로 미래 미도착 박스는 보지 않는다(청구항 10/22). 버퍼 포화
  극단에서는 회수 불가가 발생하며 이는 청구항 9·11의 대상이다.
