> 이 기록은 **브라우저 기구학/배치 모델**에 대한 것입니다. 실물 완성품이 아니며 전체 질량 감소, 물리 검증, 수치적 최적값, 제작 완료를 주장하지 않습니다.

## 1. 목적

R10 구성에서 본체 외피, 프레임, 요크를 얇게 통합해 본체 크기와 수납(stow) 행정을 줄입니다. 핀셋 팁, 엄지 동작, 척 구동 방식, 노즈와 모터/감속기 설치공간 치수는 유지합니다.

## 2. 선택 이유와 변경

| 항목                      | R10 (c2)                                             | R11                                                                                                                   |
| ------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 본체                      | Ø62 × 93 mm                                          | Ø60.5 × 89 mm                                                                                                         |
| 수납(stow) 행정           | 32 mm                                                | 29 mm                                                                                                                 |
| 노즈                      | Ø29 × 12 mm                                          | 동일 (유지)                                                                                                           |
| 외피/구조                 | 별도 커버 + 타이로드 3개 + 후방 격벽 + 커버 나사 4개 | 1 mm 구조 튜브에 가이드 일체화 (위 부품 제거)                                                                         |
| 요크 판                   | 6 mm, 반경 슬라이드 슬롯 있음                        | 3 mm, 반경 슬라이드 슬롯 삭제                                                                                         |
| 슬라이드 평면 / 링 너트   | 기준                                                 | 슬라이드 평면 +3 mm, 링 너트 −4 mm                                                                                    |

모터와 감속기 설치공간 치수는 R10과 동일하게 유지했습니다.

## 3. 계측 비교

| 지표                               | R10 (c2)       | R11            | 변화     |
| ---------------------------------- | -------------- | -------------- | -------- |
| 외접 원통 체적 (πD²L/4)            | 280,773.56 mm³ | 255,853.07 mm³ | −8.88 %  |
| 지정 구조 재료 체적                | 57,796.93 mm³  | 41,794.86 mm³  | −27.69 % |
| 알루미늄 환산 질량 (지정 솔리드만) | 156.05 g       | 112.85 g       | −27.69 % |
| 렌더 메시 개수                     | 63             | 53             | −15.87 % |

**해석 범위**

- 재료 체적과 알루미늄 환산 질량은 **지정한 외피/프레임/요크 솔리드에만** 해당합니다. 밀도 2.70 g/cm³ 알루미늄 등가 추정이며 전체 질량이 아니고 실측한 조립체도 아닙니다. 구동기, 감속기, 조, 전달 기구, 케이블, 체결구는 제외했습니다.
- 메시 63 → 53은 **렌더링 메시 개수**이며 BOM이나 실제 부품 수가 아닙니다.
- **기준선 보정**: R10 요크 캡에 비다양체(nonmanifold) 모서리가 있어 부호 체적을 쓸 수 없습니다. 선언된 2D 단면적 × 깊이(원호 256분할)로 비교했습니다. 보관된 R10 자체는 수정하지 않았습니다.

## 4. 기능 보존

- M6×20, M8×35, M10×50 대상 유지(팁 변경 없음)
- 얇은 핀셋으로 더미에서 수평 볼트 집기
- 2R 엄지가 볼트를 90° 회전
- 14 mm 인입, 방사형 조 6개, 스프링 폐쇄 척
- Ø29 × 12 mm 노즈, 고정구 없이 밀집 이웃 체결, 반력 토크는 로봇이 수용
- 3 mm 척 해제 오버트래블, 리셋, 70초 예시 FR3 사이클
- 뷰어 컨트롤 전부와 이전 버전 경로
