# R07 기계 검토 — 제작 전 구조와 하중 확인

기준일: 2026-10-01. 설계 대상은 M6~M10의 **노출된 외부 육각 헤드**이며 실제 체결 토크는 아직 정하지 않았다. 이 문서는 구조 선택과 누락 항목을 검토하는 자료다. 구매부품 선정, BOM, 제작도면, 공차 설계 또는 제작 승인이 완료되었다는 뜻이 아니다.

## R06 판정과 R07 범위

**R06은 제작 승인 기준안에서 제외한다.** 구동부와 힘 전달 경로가 빠진 동작, 최종 토크 전달 근거가 없는 얇은 B 턱, 부품 관통이 남아 있다. 과거 재생·좌표·단위 테스트의 통과는 기구 제작 가능성의 증거로 사용하지 않는다. R06의 구조 축소·경량화 표현도 실물 성능이 입증된 결과로 해석하지 않는다.

R07은 기존 시연과 구분되는 **브라우저 조립 검토 뷰**로 A/B 배치와 회전 영역을 검토한다. 실제 로봇 제어, 접촉 물리, 체결 토크 검증은 이 뷰의 결과가 아니다. B의 피벗과 카세트 배치는 아래 좌표로 구체화했다. 구매 부품·공차를 반영한 제작 도면은 아직 확정되지 않았다.

공통 조건은 다음과 같다.

- 일자 테이퍼 손가락으로 몸통을 잡고 헤드가 위를 향하도록 세운 뒤 내부 가변 6조 척으로 인계한다.
- 헤드 척의 축방향 위치는 도구 하우징에 대해 고정한다. 설명 모델에서는 자세 변환 종료 시 헤드가 척 기준면에 도달하고 픽업 슬라이드는 인계 후 수납에 사용한다. 체결 전진은 로봇의 도구 전체 이동으로 처리해야 한다. 척 내부 구동을 위한 드로바 이동과 척 자체의 돌출 이동은 구분한다.
- 회전축·척은 고정 외장 안에서 회전한다. 볼트 나사부가 밖으로 나오는 개구, 픽업 통과 슬롯, 베어링과 고정 외장의 경계를 실제 공간으로 표시해야 한다.
- 규격별 소켓 교환은 하지 않는다. 다만 실제 부품의 대변·헤드 높이·챔퍼·플랜지·와셔 유무를 측정하기 전까지 전 규격 대응을 보증하지 않는다.
- 기존 8/20/40 N·m는 오직 과거 시연값이다. 추천 토크, 측정값, 나사 규격별 적정 토크 또는 신규 설계 정격이 아니다.

## A/B의 자유도와 구속

| 항목                    | A: 엄지로 자세 변환               | B: 픽업 카세트 전체 회전                      |
| ----------------------- | --------------------------------- | --------------------------------------------- |
| 몸통 파지               | 평행 픽업 1축                     | 평행 픽업 1축                                 |
| 세우기                  | 보조 엄지의 2R                    | 픽업 카세트 전체의 1R                         |

| 체결                    | 스핀들 회전 1축                   | 스핀들 회전 1축                               |
| 합계                    | 6제어축                           | 5제어축                                       |
| 별도 검토할 수동 자유도 | 몸통 파지 접촉부의 자세 추종      | 원칙적으로 몸통은 카세트에 대해 고정          |
| 주요 공간 부담          | 엄지 링크·구동 전달부와 수납 경로 | 카세트 본체·손가락·볼트·배선의 전체 회전 영역 |

이는 독립적으로 제어해야 하는 운동 좌표의 개수이며 모터 수나 구매부품 수가 아니다. 로봇 관절은 합계에 포함하지 않았다. 잠금·클러치에 별도 구동이 필요해지면 그 구동도 추가로 계수한다. 6조 척의 동기화 구동이 실제로 설계되어야만 닫힘을 1축으로 셀 수 있다.

A는 엄지가 볼트를 돌릴 때 주집게가 허용하는 회전 자유도를 먼저 정의해야 한다. 강체로 고정한 볼트를 엄지가 관통해서 돌리거나, 파지력을 낮췄다는 이유만으로 낙하 없이 회전한다고 가정할 수 없다. 접촉 패드·베어링·마찰 조건과 엄지 접촉력이 필요하다.

**B에서는 작은 접촉 패드만 비트는 이전 제안을 채택하지 않는다.** 직선 손가락과 평행 구동부를 포함한 픽업 카세트 전체를 1R 베어링과 구동기로 돌린다. 볼트는 그동안 카세트에 대해 고정된 몸통 파지를 유지한다. 회전축의 위치가 파지점에서 떨어져 있으면 볼트도 그 오프셋만큼 원호를 그린다. 모델은 실제 피벗 위치를 사용해야 하며 볼트만 제자리에서 회전시켜서는 안 된다.

B의 1R 종료 자세에서 볼트 축과 척 축을 일치시키도록 피벗·카세트·레일을 배치해야 한다. 현재 배치에서는 90° 회전 종료점이 척의 고정된 파지 평면과 일치하고 1P는 인계 후 수납에 사용한다. 실제 헤드 착좌 오차를 이 배치만으로 흡수하지 못하면 추가 정렬 자유도나 재배치가 필요하다. 이 경우 5제어축 구조가 성립하지 않는다. **손목만 돌리면 볼트와 도구 사이 상대변환은 그대로이므로 내부 축 정렬을 대신할 수 없다.**

B는 엄지 링크를 없애지만 카세트 전체의 회전 영역과 관성이 커질 수 있다. 소형화·경량화·사이클 단축을 보장하지 않는다. 과대한 회전 영역도 그대로 표시하고 배치를 변경해야 한다. 구현되지 않은 공통 캠, 순간적인 구속 전환, 물체를 통과하는 수납 경로로 공간 문제를 해결하지 않는다.

긴 손가락은 스핀들과 회전 카세트 사이의 공간을 확보한 결과다. 기존 소형 모듈의 허용 손가락 길이를 충족한다고 가정하지 않는다. 별도의 모듈 선정, 손가락 처짐, 파지력 계산이 필요하다. B는 제어축을 하나 줄이지만 도구가 작거나 가벼워졌다는 결론은 아니다.

A의 엄지 회전에 동일한 보간을 두 번 적용해 볼트와 접촉이 어긋나던 오류를 수정했다. 엄지 모터와 평행 모듈이 12.5 mm 겹치던 설치 공간도 분리했다. 자동 검사에는 실제 렌더링 롤러의 볼트 접촉 위치와 모터 설치 공간 분리를 추가했다.

브라우저는 A/B 비교, M6/M8/M10 선택, 단계 탐색, 외장 투명 보기, 분해 배치와 GLB·CSV 저장을 제공한다. GLB는 미터 단위의 시각 조립 메시다. STEP 솔리드·치수 공차가 있는 부품도·가공용 나사 형상이 아니며 제작 발주에 사용할 수 없다. CSV도 구매 확정 BOM이 아닌 부품군 검토표다.

회전 단계는 내부 회전 경로만 보여준다. 작업물에 실제 나사를 삽입하는 해석, 토크 제어, 로봇 경로 계획은 포함하지 않는다. 애니메이션의 인계 순서는 센서 확인을 구현한 실기 제어기가 아니다.

## 연속 파지와 실제 구동 경로

인계 순서는 `몸통 파지 확인 → 통 밖 인출 → 세우기 → 축 정렬·헤드 착좌 → 헤드 척 잠금 확인 → 몸통 집게 해제 → 픽업 수납 확인 → 스핀들 회전`이다. 헤드 척이 잡았다는 확인 전에는 몸통 집게를 열지 않는다. 확인은 애니메이션 시간이 아니라 실기 센서와 힘·위치 조건으로 정의해야 한다.

척은 회전 위상이 맞는 육각을 전제로 닫는 그림만으로 끝내지 않는다. 열린 척의 저토크 위상 탐색, 잘못된 높이에서 닫힘, 헤드 모서리 걸림, 불완전 착좌를 검출할 방법이 필요하다. 몸통을 잡은 상태에서 위상 탐색할 때는 **볼트를 억지로 돌리는 것인지, 열린 척만 돌리는 것인지**를 구분한다. 6개 턱이 모두 닿았다는 위치 표시만으로 토크 전달이나 잠금이 확인되지는 않는다.

다음 힘 전달 경로가 단면과 부품으로 연결되어야 한다.

- 픽업: 구동기 → 동기화부 → 직선 가이드 → 손가락 → 몸통 접촉면. 슬라이드와 B의 회전 베어링까지 파지 하중을 전달한다.
- 척 닫힘: 구동기 → 드로바 또는 실제 구동링 → 턱 가이드·쐐기 → 헤드. 닫힘 유지 방식과 개방 복귀를 포함한다.
- 체결 토크: 스핀들 출력 → 결합부·축 → 척 몸체 → 턱 가이드·헤드 접촉부 → 볼트. 회전 중 닫힘을 유지하는 장치와 고정부/회전부 사이 구동 전달을 포함한다.
- 반력: 스핀들 고정 하우징 → 도킹 탭·키 → 작업대 지그 → 고정구. 두 탭의 균등 접촉을 보장할 수 없으면 한 탭만 접촉하는 조건도 계산한다.

주요 부품군은 평행 구동부, 손가락·패드, 슬라이드와 가이드, A의 엄지 링크·전달부 또는 B의 1R 구동·베어링, 6조 척의 턱·가이드·닫힘 구동·잠금, 스핀들과 축 결합부, 외장, 배선·배관, 센서, 반력 지그다. 이는 누락을 찾기 위한 목록이며 확정 BOM이 아니다.

## 예비 하중 계산과 해석 범위

재현 명령은 데모 디렉터리 기준이다. Python 표준 라이브러리만 사용한다.

```bash
python3 scripts/mechanical-loads.py
python3 scripts/mechanical-loads.py --torques 20 40 60 --json
# 아래는 과거 시연값의 재계산일 뿐, 토크 선정이 아니다.
python3 scripts/mechanical-loads.py --torques 8 20 40
```

스크립트는 입력 토크와 헤드 대변·축 지름의 모든 조합을 계산한다. M6에 60 N·m를 권장한다는 뜻이 아니다. 표시하는 축 지름은 **스핀들 출력축의 예시 지름**이며 볼트 호칭 지름이 아니다.

| 계산                            | 식                | 가정과 제외 항목                                                                                                       |
| ------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 헤드 등가 접선력                | `F_eq = 2T/AF`    | 대변 `AF/2`를 등가 반경으로 둔 힘. 턱의 법선력, 예압, 접촉압력이 아니다. 실제 접촉점과 토크 전달 방향은 별도 계산한다. |
| 중실 출력축 최대 전단응력       | `tau = 16T/(πd³)` | 균일한 중실 원형축의 순수 비틀림. 중공부·키홈·스플라인·단차·굽힘·피로·재료 허용응력을 포함하지 않는다.                 |
| 두 반력 탭의 탭당 힘            | `F = T/(2r)`      | 반대편 두 탭이 같은 반경에서 균등 분담. 한 탭만 접촉하면 `F = T/r`로 증가한다.                                         |
| 작은 원형 패드의 면내 마찰 토크 | `T_pad ≈ 2μNa/3`  | 반지름 `a`, 균일 압력, 패드 한 개의 법선력 `N`. 두 패드가 동일하게 기여할 때만 합계를 두 배로 계산한다.                |

위 식에서 길이는 SI 단위로 환산한다. 스크립트의 축 응력 출력은 MPa다. 원형 패드 식은 `∫ μp·r·dA`를 적분한 값이며 **패드의 법선축 주위 회전**에 해당한다. 나사산·원통 접촉이나 볼트 축 주위 체결에 그대로 적용할 수 없다. B의 카세트 전체 회전 정격을 계산하는 식도 아니다.

기본 민감도 계산 결과의 일부는 다음과 같다.

| 가정 토크 | AF 10 mm 등가 힘 | AF 13 mm 등가 힘 | AF 17 mm 등가 힘 | Ø10 mm 중실축 전단응력 | 반경 25 mm, 두 탭 중 탭당 힘 |
| --------- | ---------------- | ---------------- | ---------------- | ---------------------- | ---------------------------- |
| 20 N·m    | 4,000 N          | 3,077 N          | 2,353 N          | 101.9 MPa              | 400 N                        |
| 40 N·m    | 8,000 N          | 6,154 N          | 4,706 N          | 203.7 MPa              | 800 N                        |
| 60 N·m    | 12,000 N         | 9,231 N          | 7,059 N          | 305.6 MPa              | 1,200 N                      |

40 N·m에서 Ø6 mm 중실축의 계산 전단응력은 약 943 MPa다. 재료·열처리·안전계수가 미정이므로 합격 여부를 판정하지 않지만 가는 축을 외형만 보고 선택할 수 없다는 점은 드러난다. 6개 턱에 하중을 단순히 6등분하지 않는다. 제작 오차와 변형에 따라 일부 턱에 먼저 하중이 걸릴 수 있다.

`μ=0.2`, 패드당 `N=20 N`, `a=1 mm`를 가정하면 한 패드의 면내 마찰 토크는 약 `0.002667 N·m`, 동일한 두 패드의 이상적 합계는 `0.005333 N·m`다. 모두 측정값이 아닌 가정이다. 이 값은 작은 접촉 패드의 회전 유지가 별도 검토 대상임을 보여줄 뿐이며 특정 볼트를 돌릴 수 있는지는 실제 접촉, 무게중심, 가속도, 요구 자세변환 토크를 비교해야 판단할 수 있다.

## 제조사 공식 근거와 적용 한계

- [Festo HGDS 파지·회전 유닛](https://media.festo.com/media/114116_documentation.pdf): 파지와 회전을 별도로 구동하고 끝 위치를 검출하는 실제 구조의 참고 자료다. R07 B의 횡방향 피벗·손가락 배치를 그대로 만족하는 구매품을 선정했다는 뜻이 아니다.
- [Zimmer SBZ 회전 조](https://www.zimmer-group.com/en/products/components/handling-technology/swivel-and-rotary-modules/series-sbz): 기어 전달, 구동축 베어링, 공압 구동, 종동 베어링, 끝 위치 검출·감쇠를 명시한다. 회전축을 점 하나로만 그리지 않도록 부품 구성을 정할 때 참고하는 근거이며 R07 장착 치수나 성능의 근거는 아니다.
- [SCHUNK GFS 적용 사례](https://bluejournal.schunk.com/en/01-25/a-perfect-solution-for-the-future/): 파지한 작업물을 회전시키는 상용 구조의 사례다. 큰 작업물용 회전 핑거를 작은 테이퍼 팁에 같은 비율로 축소할 수 있다는 근거로 사용하지 않는다.
- [Zimmer GD303 제품 자료](https://www.zimmer-group.com/fileadmin/pim/MER/GD/PG/MER_GD_PG_GD303NO-C__SEN__APD__V1.pdf): 동기화 쐐기 구동, 턱 가이드, 파지력 유지 스프링, 위치 검출을 확인할 수 있다. 3조 핸들링 그리퍼의 자료이므로 자체 6조 체결 척의 토크 정격을 보증하지 않는다.
- [DESTACO 그리퍼 선정과 파지 방식](https://www.destaco.com/company/news/know-what-to-consider-when-selecting-the-proper-gripper): 손가락 길이·파지력·접촉 형상·유분·동력 상실 시 유지 문제를 구분한다. R07에서는 몸통 파지와 헤드 토크 전달을 같은 기능으로 취급하지 않는다.
- [Kolver KDUCER 카탈로그](https://kolver.com/upl/EN_Catalog_KDUCER.pdf): 기존 시연의 스핀들 설치 공간 참고 출처다. 토크 미정인 R07의 구매 선정 또는 정격 확정 자료로 사용하지 않는다.
- [Franka 제어 파라미터](https://support.franka.de/docs/control_parameters.html): 로봇의 제한을 확인하는 공식 출처다. 이것만으로 완성 도구의 적재 하중, 손목 반력 또는 도킹 설계가 검증되는 것은 아니다.

공식 제품의 존재는 해당 원리와 부품 구성을 설명하는 근거다. R07 조립체의 강도, 간섭 없는 운동, 낙하 방지, 목표 체결 품질은 위 수용 기준에 따라 별도로 입증해야 한다.
