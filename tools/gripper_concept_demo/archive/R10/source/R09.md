# R09 · 핀셋형 소형 그리퍼 + FR3 빈피킹

## 목적

R08이 하던 일(몸통 파지, 엄지로 세우기, 인입, 헤드 척 고정, 회전 체결)과 안전 순서는 유지하면서 몸체를 최대한 줄였다. 세 가지 현장 조건을 반영했다.

1. 무더기에서 집기: 집게를 털 뽑는 핀셋처럼 납작하고 끝이 가는 날로 바꿨다.
2. 장소 무관: 지그나 키홈 없이 평면 작업물에 바로 체결한다.
3. 촘촘한 볼트 벽: 척을 가는 노즈 끝에 두어 몸체가 이웃 볼트 머리 위로 지나가게 했다.

## R08 → R09

| 항목           | R08                     | R09                                                           |
| -------------- | ----------------------- | ------------------------------------------------------------- |
| 몸체 외형      | 152 × 144 × 250 mm      | 61 × 59 × 81 mm + 노즈 Ø29 × 12 (공구 길이 93, 부피 6.1%)     |
| 집게           | 경사 손가락 + 접힘 힌지 | 핀셋 날 2개: 판재 4.4 × 1.2 → 끝 1.2 × 0.5, 평행한 집는 면    |
| 몸통 해제      | 90° 접은 뒤 수납        | 노즈 바깥까지 벌린 뒤 몸체 안으로 뺌                          |
| 인입 / 수납    | 50 / 70 mm              | 14 / 32 mm                                                    |
| 보조 엄지      | 38 + 38 mm              | 24 + 24 mm, 파지 중 핀셋 끝보다 위로 접힘                     |
| 회전 척        | Ø56, 6조                | Ø27.6, 6조, 노즈 끝에 고정 (축방향 이동 0)                    |
| 최소 볼트 간격 | 정의 없음               | M6 22 / M8 24 / M10 26 mm (노즈 반경 + 이웃 머리 대각 + 1 mm) |
| 구동부         | 7개                     | 5개 (개폐, 엄지 2, 인입, 척 폐쇄, 회전) · 드라이버는 외부     |
| 체결 반력      | 정의 없음               | 로봇팔이 받음                                                 |

## 동작 순서 (FR3, 70 s)

접근 → 핀셋 파지 → 인출 → 엄지 접근 → 세움 → 엄지 접기 → 인입 14 mm → 헤드 척 → 핀셋 벌림 → 수납 32 mm → 작업물 위로 이동 → 수직 하강(노즈만 이웃 볼트 사이로) → 회전 체결 → 해제 → 복귀하며 재장전.

R08과 달리 엄지는 인입 **전에** 접는다. 파지 시점에 엄지가 핀셋 끝보다 앞으로 나오지 않게 하려면 엄지를 뒤로 접어야 하는데, 뒤로 접힌 엄지가 몸체 안으로 들어가는 경로는 인입 전에만 열린다. 엄지를 접은 뒤에도 세운 볼트는 핀셋 끝 패드에 매달려 있다.

## 연결 구조

- 프레임: 노즈 관 → 전면판(작업 포트) → 타이로드 4개 → 모터판 → 후면 격벽 → FR3 어댑터 링.
- 체결축: 모터판 → 모터 → 감속부 → 출력축 → 척 → 6개 반경 슬라이더 → 턱. 폐쇄 액추에이터는 감속부를 감싼다.
- 인입: 가이드 2개와 이송나사(프레임) → 부싱·너트 → 요크 → 개폐 슬라이드 → 핀셋 날 → 끝 패드. 요크 → 엄지 기둥 → 축 → 링크1 → 링크2 → 롤러.
- 외장 슬리브는 비구조 커버라서 연결 검사에서 뺀다.

## 검증 (`tests/compact.test.ts`)

- 모든 단계와 규격에서 부품 OBB 접촉 그래프가 하나로 이어진다. 부품을 일부러 떼어 낸 대조 시험도 포함한다.
- 파지 시점에 볼트에 닿는 것은 핀셋 끝뿐이고, 엄지는 핀셋 끝보다 6 mm 이상 위에 있다.
- 체결 중 이웃 볼트 머리 높이(머리 높이 + 3 mm) 안의 모든 꼭짓점이 노즈 반경 안에 있다.
- 핀셋 날이 노즈와 척을 침범하지 않는다. 엄지 링크는 핀셋에 닿지 않고, 접혀 들어갈 때 노즈 밖·포트 안을 지난다.
- R08 인터록이 지켜지고, 체결 중 볼트 말고 앞으로 나오는 부품이 없다.
- FR3 관절 한계를 지키고, 볼트 인계가 연속이며, 사이클이 끝나면 초기 상태로 돌아온다.

FR3 경로는 `python3 scripts/generate-motion.py --profile r09`로 만들고 `src/compact-motion-data.json`에 저장한다. 시뮬레이션 작업물에는 목표 구멍을 둘러싸고 최소 간격 + 0.5 mm 위치에 체결된 이웃 볼트 6개가 있다.

## 범위와 한계

동작과 배치를 보여 주는 시각 모델이다. 반력은 로봇팔이 받는다. FR3 손목 관절 정격은 약 12 Nm라서 M8·M10 예시 토크(20/40 Nm)에는 더 큰 팔이 필요하다. 다음은 검증하지 않았다.

- 핀셋 끝의 강성과 마모
- 엄지를 접은 뒤 인입하는 동안 볼트 자세가 유지되는지
- 무더기 속 충돌 (파지 시 몸체가 통 안 볼트 위로 약 40 mm까지 내려간다)
- 질량과 강도

구동부는 아직 고르지 않았다. 제작 승인 도면이 아니다.
