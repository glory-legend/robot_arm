# R10 · 원통형 + 캠 연속 스트로크 (시안 2 채택)

## 결정

2026-10-01 R10 시안 검토에서 시안 1·2·3을 3D 모델로 비교한 뒤 시안 2를 채택했다. 다섯 시안과 모델 비교는 Notion "R10 시안 검토 · 굴곡면·협소 공간 대응 외형 (5안)"에 남아 있다. 핀셋 날, 엄지, 척, FR3 동작은 R09와 같다.

## R09 → R10

| 항목           | R09                                   | R10                                                         |

| 외형           | 61 × 59 상자형 × 93                   | Ø62 원통 × 93 (단면 −16%, 모서리 없음)                      |
| 이송           | 가이드 2개 + 이송나사 + 후방 이송모터 | 링 모터 → 스핀들을 감싼 나사 슬리브 → 요크 링 너트          |
| 요크 회전 방지 | 가이드 로드                           | 타이로드 3개                                                |
| 척 닫기        | 척 폐쇄 구동부                        | 스프링 상시 닫힘 + 단방향 트리거, 해제는 요크 초과행정 3 mm |
| 핀셋 벌림      | 개폐 구동부가 별도 단계로 실행        | 수납 스트로크 첫 0.6 mm에서 고정 캠이 벌림                  |
| 공정           | 14단계                                | 11단계                                                      |
| 구동부         | 6개                                   | 5개 (개폐, 엄지 2, 이송, 회전)                              |

## 한 스트로크 (15.5–25 s)

요크가 +14 mm에서 −32 mm까지 한 번 물러나는 동안 다음이 차례로 일어난다.

1. 볼트를 당겨 헤드가 척에 들어간다.
2. 요크가 원점을 지나는 순간 트리거가 스프링 척을 닫는다.
3. 다음 0.6 mm 동안 캠이 핀셋을 노즈 바깥까지 벌린다.
4. 남은 거리만큼 수납한다.

체결이 끝나면 요크가 3 mm 더 물러나서(초과행정) 해제 로드로 척을 열고 래치한다. 재장전할 때는 요크가 앞으로 이동하는데, 트리거가 단방향이라 이때는 척이 닫히지 않는다.

  - 체결 때 이웃 볼트 머리 높이 안에 노즈만 있는지
  - 핀셋과 노즈, 엄지와 핀셋의 간섭
  - 동작 인터록, FR3 관절 한계, 볼트 인계 연속성, 사이클 복귀
- 단위 검사 72개와 브라우저 검사 18개를 통과했다.

## 한계

다음은 시각 모델로 확인할 수 없어 실물 검증이 필요하다.

- 스프링 척의 파지력
- 트리거와 래치의 신뢰성
- 캠 마모
- 엄지를 접은 뒤 인입하는 동안 볼트 자세가 유지되는지

체결 반력은 로봇팔이 받는다. 노즈 끝 모따기(Ø22 접촉 링)는 Ø27.6 척과 맞지 않아 넣지 않았다. 제작 승인 도면이 아니다.
