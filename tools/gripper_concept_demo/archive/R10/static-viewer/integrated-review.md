# R08 · 공통 몸체 통합형 그리퍼

## 설계 목적

파지·볼트 정렬·헤드 고정·체결 기구를 하나의 프레임에 지지한다. 중앙에는 고정된 위치에서 회전하는 6조 척과 동축 구동부를 두고 양옆에는 집게 수납 공간, 뒤쪽에는 보조 엄지와 인입 구동부를 배치한다. 외장은 분할 커버로 정비할 수 있게 한다.

## 동작과 내부 배치

1. 얇은 일자형 테이퍼 팁 두 개로 헤드 가까운 몸통을 잡는다. 빈에서 들어 올리는 로봇 동작은 이 모델의 범위 밖이다.
2. 공통 캐리지에 장착한 2관절 엄지가 볼트 끝부분을 눌러 세운다. 주집게의 접촉 패드는 수동 회전한다.
3. 파지를 유지한 채 캐리지가 50 mm 들어가 헤드를 고정 척에 넣는다. 체결 척 자체는 축방향으로 전진하지 않는다.
4. 헤드 척을 닫은 뒤 엄지를 접고 몸통 집게를 연다. 실물에서는 착좌·파지·잠금 확인 센서가 필요하다.
5. 주집게를 바깥쪽으로 90° 접은 다음 캐리지를 70 mm 더 당겨 본체 양옆에 수납한다. 집게를 접는 동안에는 캐리지를 멈춘다.
6. 집게와 엄지가 수납된 상태에서 중앙 척과 볼트만 회전한다. 외장과 프레임은 고정한다.

엄지의 2R 링크 운동 평면은 볼트 중심에서 옆으로 16 mm 떨어뜨리고 가로축 롤러가 볼트에 접촉하도록 배치한다. 접힌 엄지는 후면 커버 안에 들어오도록 경로를 조정한다. 척 슬라이더의 방사형 슬롯은 실제 빈 형상으로 표현한다.

## 검토 범위

브라우저 모델은 기구의 배치와 순서를 검토하는 시각 모델이다. 파지 유지, 엄지의 도달 범위, 고정 척 위치, 접힘과 수납 순서를 수치 검사한다. 전체 형상의 연속 충돌 검사, 강도·공차·열·케이블 수명·체결 토크 검증은 포함하지 않는다. 척 잠금과 회전 중 폐쇄력 유지 방식, 센서, 감속기와 베어링 정격도 상세 설계가 필요하다. 이 상태로 제작을 발주할 수는 없다.

사진은 R08 구현에서 직접 캡처하고 GLB는 미터 단위의 시각 메시로 저장한다. 이전 버전의 사진과 소스는 수정하지 않는다.
