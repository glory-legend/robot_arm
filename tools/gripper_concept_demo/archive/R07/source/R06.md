# R06 · 내부 회전 체결의 두 가지 구조

2026-09-30 설계 조건: 일자형 테이퍼 팁을 더 날카롭게 하고 체결부가 앞으로 튀어나오지 않게 한다. A는 내부 체결부에 인계하고 주집게를 수납하는 안, B는 전체 과정을 더 적은 구조와 움직임으로 처리하는 안이다. B를 단순 절첩형으로 해석한 제안은 정정했으며 해당 제안은 채택하지 않았다.

## 공통 조건

- 대상: M6×20 / M8×35 / M10×50. 같은 부품에서 파지 간격을 바꾼다.
- 팁: 뿌리 6×5mm → 끝 1.6×2.4mm, 평면으로 깎은 3단 테이퍼. 무한히 날카로운 칼날 대신 작은 평면 접촉 패드를 남겼다. 이전 R05는 8×8→3×4mm였다.
- 헤드 가까운 몸통을 잡은 상태에서 작은 2R 엄지(25+25mm)로 볼트를 세운다. 헤드 위·나사 끝 아래.
- 체결 회전축과 헤드 접촉면의 축방향 위치는 고정이다. 이전 18mm 착좌 전진축을 없앴다. 볼트 삽입은 로봇팔이 도구 전체를 전진시킨다.
- 고정 외장 안의 회전부만 회전한다. 외장에는 엄지/기구가 빠져나가는 뒤쪽 개구가 있으며 완전 밀폐 구조가 아니다. 개념 외장 내반경 39mm/외반경 42.5mm.
- 체결 스핀들의 기존 실제 설치 공간을 유지한다. 이 모델은 토크를 만들어내는 구동부를 작게 생략하지 않는다.
- 보조 엄지, 반력 지그, 나사 피치별 회전·전진, 최종 체결 단계는 두 안 모두 유지한다.

## A · 별도 내부 척 + 주집게 수납

몸통을 집는 두 팁과 6조 헤드 척의 기능을 분리한다. 헤드 척은 처음부터 본체 안의 고정 위치에 있고 수직 정렬 후 방사 방향으로만 닫힌다. 헤드를 확보한 다음 주집게 모듈이 뒤 52mm·위 20mm, 총 55.7mm 이동하여 수납된다. 엄지도 뒤로 빠지고 접힌다.

몸통 파지와 헤드 토크 전달을 독립적으로 설계할 수 있다는 장점이 있다. 반면 별도 6조 척, 파지 인계, 긴 수납 가이드와 공간이 필요하다. 소형 평행 구동부는 기존 Zimmer급 설치 공간을 참고하며 새 수납부는 자체 개념이다.

## B · 파지·체결 통합 2조 카세트

두 개의 회전 집게 카세트 각각에 몸통 파지용 얇은 팁과 헤드용 접촉면을 둔다. 헤드 접촉면의 잠금을 확보한 다음 몸통 팁을 벌리고 24mm만 수납한다. 이후 두 카세트가 볼트와 함께 본체 안에서 회전한다. A의 별도 6조 척을 제거한다.

B는 두 기능을 같은 카세트로 묶는 구조 축소안이다. 팁을 접는 대안은 아니다. 공통 인덱스 캠이 몸통 파지→헤드 접촉면 잠금→팁 수납의 순서를 연계하도록 제안한다. 현재 모델은 이 순서를 결정론적 경로로 표현하며 캠 홈, 스프링, 힘 제어, 잠금 강도까지 제작 설계한 것은 아니다. 부품 수·질량의 최적해를 입증하거나 임의 형상의 헤드를 체결한다고 주장하지 않는다.

두 접촉면의 파지 구간을 겹쳐 볼트가 완전히 놓이는 순간을 만들지 않는다. 실제 미끄럼·변형·실패 감지와 복구는 시제품에서 확인해야 한다. 대변 10/13/17mm의 육각 헤드를 전제로 한다.

## 시연과 자료 관리

오른쪽 A/B 버튼으로 같은 시각을 유지하며 바꿔 볼 수 있다. 규격 변경 시에는 동작을 처음으로 돌린다. `?variant=a` 또는 `?variant=b`로 직접 접근할 수 있다. 내부 회전 비교 버튼은 외장을 투명하게 하고 체결 단계로 이동한다.

R05 원본은 `archive/R05/`와 ZIP에 보존했다. R04 부분 소스, DG3FM 부분 소스·원본 자산도 별도 보존했다. Notion의 **Bin_Picking 문서 → 볼트 그리퍼 설계·모델링 버전 기록**에서 버전별 문서와 자료를 관리하며 확보하지 못한 초기 원본과 사진은 복원 완료로 표시하지 않는다.

전체 메쉬의 연속 충돌·접촉 물리·실물 토크 검증은 이 시연의 범위가 아니다. 자동 검사는 고정 체결축, 강체 팁 길이, 접촉 순서, 끝 위치 간극, FR3 관절 제한과 피치별 회전·전진을 대상으로 한다.
