# 볼트 그리퍼 동작 연구실

한국어 단일 화면 엔지니어링 시연으로 로봇 전체 동선과 내부 파지 인계를 설명한다. 실제 제어·물리 해석을 표시하지 않는다.

## Visual system

- Canvas/background: #e9edef; panel: #f8fafb; ink: #20313d; muted: #5c6d78; line: #d5dfe5.
- 테이퍼 주집게 #4c5a63, 헤드 척 #bb591f, active #185c56. 색상과 부품명을 함께 사용.
- 본문: 로컬 Noto Sans CJK KR / Malgun Gothic / sans-serif. 제목도 같은 계열의 굵은 글꼴, 수치: ui-monospace.
- 데스크톱: 전체 높이 작업 공간, 우측 300px 설명 패널, 하단 타임라인. 모바일: 캔버스 다음 설명 패널, 세로 스크롤.
- 전체 로봇과 동기화된 그리퍼 확대 카메라가 시각적 중심. 장식적 애니메이션은 없음.
- 토큰 소유자는 src/style.css의 :root, Three.js 재질은 src/theme.ts. 3D 재질 색상은 같은 CSS 토큰에서 읽음.

## Controls

네이티브 button, select, range, checkbox를 공유 스타일로 사용한다. select의 OS 팝업 허용. UI는 ko-KR. 키보드 포커스 표시와 이름 제공.
초기 정지, 사용자 재생만 허용. 시점 전환은 reduced-motion이면 즉시 수행. 장면 실패는 인라인 오류와 다시 불러오기.
볼트 변경은 정지/초기화. 분해 보기는 정지시키고 재생 시 조립 복원. 시점 변경은 타임라인 보존.

## R05 구조

일자형 테이퍼 팁 두 개로 몸통을 파지하고 작은 2R 보조 엄지로 세운다. 규격 교환 없이 다중 턱으로 헤드를 유지하고 최종 체결한다. 주집게의 생체모방 관절 형상은 폐기했다. R05는 Zimmer 소형 평행 모듈 및 Kolver 체결 스핀들의 실제 설치 공간을 기준으로 자체 팁·6조 척·후퇴 레일을 배치한다. 선정 근거와 한계는 REDESIGN.md가 최신 문서다.

팁은 금속, 엄지는 청록색, 척 접촉 턱은 주황색으로 표시한다. 상세 보기에서는 접촉부를 확대하고 전체 보기에서는 긴 체결 구동부까지 보여준다. 상용품 설치 공간과 자체 기구를 구분하고 실제 성공률·측정 토크를 암시하지 않는다. 기존 재생·단계 탐색·모바일 동작은 유지한다.

## R06 비교

동일 단계에서 A 분리 수납형과 B 파지·체결 통합형을 전환한다. B는 단순 접힘안이 아니라 구조 축소안이다. 체결부 축방향 전진은 0mm이며 고정 외장과 내부 회전을 색과 투명 보기로 구분한다. 날카로운 팁의 단면·접촉 패드를 보여주되 제조 검증 완료를 암시하지 않는다. 최신 스펙은 R06.md를 참조한다.

## R07 조립 검토

기본 화면을 조립 뷰로 바꿔 부품 지지·연결·회전 공간을 보여준다. A는 기능을 분리하고 B는 픽업 카세트 전체 1R로 도구 제어축을 축소한다. 기존 R06은 concept.html에 보존한다. 치수는 공간 검토값으로 표시하고 토크 미정·제작 미승인·구매부품 미선정을 숨기지 않는다. 회전 중 볼트가 실제 피벗에서 원호를 그리도록 하고 비교 시 진행률을 유지한다. GLB는 미터 단위 시각 메시, CSV는 부품 검토표이며 제작도면이나 확정 BOM으로 부르지 않는다.

## R08 공통 몸체 조립 검토

R08은 engineering.css의 화면 구성을 이어받고 공통 몸체 하나를 장면 중앙에 배치한다. 전체·확대·측면·정면 시점을 제공하며 투명 보기 또는 커버 제거로 내부 기구를 확인한다. 처음에는 정지하고 재생·수동 탐색·규격 전환·GLB·CSV 저장을 제공한다. R07의 engineering.html과 R06의 concept.html로 이동하는 링크를 유지한다.

공통 프레임과 분할 커버, 중앙 고정 척, 양옆 집게 수납 공간, 뒤쪽 엄지·인입 구동부를 구분해 보여준다. 치수는 R08.md를 기준으로 하며 공간 검토값임을 표시한다. 토크·전체 질량 미확정, 구동부 미선정, 제작 미승인 상태를 유지하고 사진은 R08 구현에서 직접 캡처한다.
