# 무더기 볼트용 그리퍼 선정 — 2026-09-30

## 이번 시연에 적용한 구성

**Robotiq 2F-85 + 규격별 슬림 교환 손끝 + 2관절 보조 엄지 + 별도 헤드 척**을 적용한다. 두 집게·관절 동작·몸통 파지·헤드 위로 세우기·깔때기 제거 조건을 유지하면서 실제 제품의 링크 구조를 기준으로 삼기 위해 선택했다. 모든 무더기 볼트 조건에서 최적인 제품을 입증한 결론은 아니다.

## 구현 및 확인 순서

1. 설치된 ROS 패키지의 실제 메시 7개와 URDF를 시연 안에 보존하고 라이선스·해시를 포함한다.
2. 관절 축과 링크 치수를 유지하고 고정 길이 슬림 손끝을 규격별로 추가한다.
3. 본체 옆에 2관절 엄지를 배치한다. 리프트 후 접촉 → 낮은 파지력 가정 → 끝부분을 눌러 헤드 위로 정렬 → 헤드 척 인계 → 손끝 이탈 순서로 재생한다.
4. 척의 개방 반경을 24mm로 하고 허브를 뒤로 옮겨 M6/M8/M10의 회전 중 헤드 공간을 확보한다.
5. FR3 경로를 새 파지 높이에 맞춰 재계산하고 관절 범위·접촉·인계·브라우저 조작과 렌더링을 확인한다.

## 실물 선정 전에 남은 조건

볼트 재질·유분·규격 범위·빈 깊이·목표 사이클이 아직 지정되지 않았다. 실제 볼트로 단품 파지 성공률, 복수 파지율, 최하층/벽면 접근, 파지력 감소 중 낙하와 회전 제어를 평가해야 최적화 여부를 판단할 수 있다. 보조 엄지와 척을 포함한 전 기구 간섭, 체결 토크 전달, 장착 강성도 미검증이다. 현재 결과는 브라우저용 동작 설명 모델이며 실제 로봇 명령을 변경하지 않는다.
