# R11 특허 검토용 도면 초안

R11 조립 모델을 선화로 정리했습니다. A4 가로 PDF 세 쪽과 그림 PNG 일곱 장입니다. 각 PNG는 1600 × 1400 픽셀, 300 dpi 흑백입니다.

- FIG. 1: M8 파지 자세의 조립 외관과 참조부호
- FIG. 2: 작업단 정면
- FIG. 3: 외피를 숨긴 내부 배치 참고도. 단면도는 아닙니다.
- FIG. 4A–4D: M8 파지, 엄지 정렬, 정지 인계, 체결 순서

이 검증은 모델의 기구학/배치 로직과 빌드 상태에 대한 것이며 물리적 성능 검증이 아닙니다. 치수 공차, 실제 구동기 설치, 잠금·해제 전달경로, 강도와 물리 동작은 확인하지 않았습니다. 제출 전에 변리사와 도면 및 청구항 대응을 검토할 수 있도록 만든 초안이며, 제작 승인 도면이 아닙니다.

파일 해시와 규격은 `manifest.json`에 기록했습니다.
